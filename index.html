Boardroom

A live board of AI advisor simulations for hard business decisions.

Advisors are AI simulations inspired by public frameworks. They are not the real people, and nothing here is affiliated with or endorsed by them.

Start a debate

No API key is entered here. Calls go through this deployment's own server function, which holds the key server-side. Setup for your own deployment is in the README.

If you leave "Do nothing" out, it is added automatically, so the board always weighs doing nothing.

How a debate works

Full runs the whole council: brief, openings, fault lines, debate, an adversarial discussion round where each seat first steelmans another seat's actual point in a labelled field, attacks its weakest premise, concedes only when beaten with a reason, and prices being wrong, draft resolution, vote, verdict. Discussion targets are assigned so seats do not all pile onto one opponent, and a target name that is a topic, pillar, or dimension is resolved to the seat that owns it, so a card always answers a real seat. Quick skips debate rounds, the discussion round, and the draft stage. Consult asks one seat a single question, with no scoring and no saved session.

Each seat speaks from a distilled brain slice for that step, never a whole brain at once. Debate and discussion slices carry the seat's sharpest test; final slices carry the strongest counter to the seat's own lens. The seats sit around a round table, with the decision title in the centre, and an animated dashed arc runs across the table from speaker to target. While a step's model call is in flight, that seat shows a thinking bubble, a slow ponder tilt, and a Thinking label, and no seat speaks yet; director and draft waits show a Director working row instead. The debate loop waits for each line to finish revealing before the next seat starts thinking, so live speech gets real screen time. After each step, the latest line plays back word by word on the stage: the speaking character lifts, tilts its head, and its mouth moves on its face with the words, it turns and leans toward the seat it answers using the real table angle, an animated dashed arc runs between them, idle seats turn toward the live seat, and the addressed seat nods or shakes from its vote or card data, never from tone. Clicking a seat, or focusing it with the keyboard, focuses its latest line and replays it the same way. Voice is optional, uses only your browser's built-in speech, and is off by default. The mouth movement is a stylised indicator, not lip-sync to a real person.

When Groq is rate-limited, the server tries free OpenRouter models in the same call, with no extra click. Each transcript step shows a small badge naming which provider and model served it. A fallback attempt can still fail, for example by timing out; then the step pauses with the fallback status and detail shown, and a retry runs only that step. If every free fallback fails, the error explains the OpenRouter free limits, so a daily cap reads as a daily cap, not as a mystery. If a debate is interrupted, reload and resume it from the next undone step; earlier steps are not rerun.

Custom advisor (optional)

Add one advisor of your own. Give a name and the viewpoint it must argue from, and it joins the debate like any other seat.

Resume an unfinished debate

Resuming continues from the next undone step. Earlier steps are not rerun, and no key is ever stored with a saved debate.

Retrying runs only the failed step. Earlier steps are not rerun and nothing is lost.
