Boardroom

A live board of AI advisor simulations for hard business decisions.

Advisors are AI simulations inspired by public frameworks. They are not the real people, and nothing here is affiliated with or endorsed by them.

Start a debate

No API key is entered here. Calls go through this deployment's own server function, which holds the key server-side. Setup for your own deployment is in the README.

If you leave "Do nothing" out, it is added automatically, so the board always weighs doing nothing.

Full runs the whole council: brief, openings, fault lines, debate, an adversarial discussion round where each seat steelmans another seat's actual point, attacks its weakest premise, concedes only when beaten, and prices being wrong, draft resolution, vote, verdict. Quick skips debate rounds, the discussion round, and the draft stage. Consult asks one seat a single question, with no scoring and no saved session.

Each seat speaks from a distilled brain slice for that step, never a whole brain at once. Debate and discussion slices carry the seat's sharpest test; final slices carry the strongest counter to the seat's own lens. After each step, the latest line plays back word by word on the stage, with mouth states and a lean toward the seat being answered. Voice is optional, uses only your browser's built-in speech, and is off by default.

If Groq hits its rate limit, the server instantly tries free OpenRouter models instead, with no extra click. Each transcript step shows a small badge naming which provider and model served it.

Custom advisor (optional)

Add one advisor of your own. Give a name and the viewpoint it must argue from, and it joins the debate like any other seat.

Retrying runs only the failed step. Earlier steps are not rerun and nothing is lost.
